# 직접 쓰는 글 가이드 (식단 예시 · 경험담 · 재료별 후기)

공식 자료를 요약한 글만으로는 글이 서로 비슷해져요. **광고 심사와 검색에서 가장 힘이 되는 건 직접 해 본 이야기**예요. 아래 방법대로 쓰면 돼요. 파일은 `src/content/guide/`에 넣고, 글 구조는 `docs/GUIDE_CONTENT.md`를 보세요.

## 1. 세 가지 글 유형
| 유형 | 무엇을 쓰나 | 분량 | 템플릿 |
|---|---|---|---|
| **재료별 후기** | 한 재료를 시작한 3일, 준비 방법, 반응, 큐브 보관, 아쉬운 점 | 1,000자 안팎 + 사진 1~2장 | `docs/guide-templates/review-beef-month7.json` |
| **식단 예시** | 실제로 먹인 한 주 식단표, 장보기, 큐브 준비 일정 | 식단표 이미지 + 800자 안팎 | `docs/guide-templates/plan-month7-week1.json` |
| **경험담** | 문제 → 해 본 것 → 결과 → 배운 점 | 1,000자 안팎 | `docs/guide-templates/story-start-with-one-meal.json` |

템플릿을 `src/content/guide/`로 복사하고 `[대괄호]` 부분을 채우면 돼요. `"experience": true`라서 글 위에 "직접 해 본 경험이에요. 모든 아기에게 똑같지 않아요" 안내가 자동으로 붙고, 출처 칸은 (출처를 안 적었다면) 보이지 않아요. 처음엔 `"draft": true`로 두고, 다 쓰면 그 줄을 지워 공개해요.

## 2. 쓰는 방법 (공통)
1. **본 것만 써요.** 날짜, 실제 월령, 먹은 양, 아기 반응을 기억이 아니라 **맘마 기록을 보고** 적으면 정확해요(식단 탭, 리포트).
2. **좋은 점과 아쉬운 점을 둘 다** 써요. 거부한 날, 실패한 날, 바꾼 점이 가장 읽을 만한 부분이에요.
3. **"우리 아기는 이랬다"로 써요.** "~하면 좋다", "~가 필요하다"처럼 일반화하거나 건강 효과를 주장하지 말아요. 건강 수치·효과는 출처 있는 가이드 글에서만 다루고, 필요하면 그 글을 링크해요.
4. **반응이 있었던 날은 사실만** 적어요. "알레르기였다"고 단정하지 말고, "두드러기가 올라와서 소아과에 갔고 의사 선생님이 ~라고 하셨다"처럼 겪은 일로 써요. 응급 상황 조언은 쓰지 않아요.
5. 마지막에 **"아기마다 다르니 걱정되면 소아청소년과와 상담해 주세요"**를 넣어요(경험 글에는 자동 안내가 붙지만 본문에도 한 줄 있으면 좋아요).
6. **구체적인 제목**을 써요. 예: "생후 7개월 소고기 이유식 첫 3일 후기" (좋음) / "이유식 후기" (약함).
7. 다른 글을 **복사하지 않아요.** 비슷한 내용이 이미 있다면 우리 경험에서 다른 점만 써요.
8. 제휴 링크를 넣으면 "제휴 링크로 수수료를 받아요"를 같이 적어요(광고·제휴 표기 의무).

## 3. 이런 건 쓰지 않아요
- 아기 **얼굴, 실명, 정확한 생년월일, 사는 동네**. 월령(예: 7개월)만 써요.
- 약·영양제 추천, "~에 좋다/나쁘다" 같은 건강 효과 주장(출처 없이는 금지).
- 다른 아기·가족의 사진이나 개인정보.
- 병원에서 들은 말을 일반 의학 조언처럼 쓰는 것.

## 4. 사진 넣는 법
사진은 직접 찍은 것만 쓰고, 글의 신뢰를 가장 많이 올려 줘요.
1. **개인정보 제거**: 휴대폰 사진에는 위치 정보가 들어 있어요. Windows에서 파일 우클릭 → 속성 → 자세히 → "속성 및 개인 정보 제거"로 지우거나, 사진을 캡처해서 써요. 아기 얼굴은 나오지 않게 찍거나 가려요.
2. **크기**: 가로 1200px 이하, 파일 200KB 안팎(JPG)으로 줄여요. 너무 크면 느려져요.
3. **파일 위치**: `public/guide-img/` 폴더에 영문 소문자 이름으로 넣어요(예: `beef-prep.jpg`).
4. **글에 연결**: 해당 섹션에 `img`를 넣어요.
   ```json
   {
     "h": "준비한 방법",
     "p": ["핏물을 빼고 삶아서 갈았어요."],
     "img": { "src": "/guide-img/beef-prep.jpg", "alt": "큐브 트레이에 담은 소고기 이유식", "caption": "소분해서 얼리는 모습", "w": 1200, "h": 800 }
   }
   ```
   `alt`는 사진을 못 보는 사람을 위한 설명이에요(꼭 쓰세요). `w`, `h`는 사진의 가로·세로 픽셀(화면이 덜컹거리지 않게).
5. **식단표 이미지**: 맘마의 식단 탭(또는 PC) → "이미지로 공유" → **이미지 저장**으로 받은 PNG를 그대로 넣어요(아기 이름은 기본으로 빠져 있어요).

## 5. 글 한 편 만드는 순서
1. 템플릿을 `src/content/guide/`로 복사하고 파일 이름과 `slug`를 같게 바꿔요(영문 소문자·하이픈).
2. `title`, `description`, `sections`의 `[대괄호]`를 채우고, `updated`를 오늘 날짜로 고쳐요.
3. 사진을 넣고 `img`를 연결해요.
4. `npm run dev`에서 `/guide/<slug>`로 확인해요. 모바일 폭(390px)도 봐요.
5. 아래 체크리스트를 보고 `"draft": true` 줄을 지워요.
6. 저에게 "커밋·푸시"를 요청하면 배포돼요.

## 6. 공개 전 체크리스트
- [ ] 내가 직접 겪은 일만 썼다 (복사한 문장 없음)
- [ ] 아기 얼굴·이름·정확한 생일·동네가 없다
- [ ] 사진의 위치 정보를 지웠고 alt를 썼다
- [ ] 건강 효과·권장치를 단정하지 않았다 (필요하면 출처 있는 글로 링크)
- [ ] 반응이 있었던 일은 사실만, 진단 단정·응급 조언 없음
- [ ] "아기마다 다르다, 걱정되면 상담" 문구가 있다
- [ ] 제목이 구체적이고 분량이 1,000자 안팎이다
- [ ] 제휴 링크가 있다면 표기했다

## 7. 글감 아이디어
- 재료별 후기: 소고기, 닭고기, 애호박, 브로콜리, 감자, 단호박, 사과, 배, 두부 … (재료마다 한 편)
- 식단 예시: 7개월 한 주, 8개월 한 주, 하루 1회로 시작한 첫 2주, 큐브만 쓴 한 주
- 경험담: 거부해서 힘들었던 재료와 다시 성공한 방법, 큐브 만들기 시행착오, 외출할 때 이유식, 가족이 함께 식단을 관리해 본 경험(맘마 가족 공유)
- 맘마 활용: 알레르기 테스트를 월~수로 해 본 기록, 병원에 알레르기 기록을 출력해 가져간 경험
