# 약관·동의·탈퇴

공개(스토어 제출·광고 신청) 전에 반드시 끝내야 하는 항목이에요. 코드는 들어 있고, **운영자 정보를 채우는 일과 문서 검토**가 남아 있어요.

## 어디에 뭐가 있나

| 기능 | 위치 |
|---|---|
| 문서 버전·운영자 정보 | `src/data/legal.ts` |
| 약관·방침·삭제 안내 본문(초안) | `src/data/legalText.ts` |
| 공개 페이지 `/terms` `/privacy` `/delete-account` | `src/pages/LegalPage.tsx` (로그인 없이 열림, `App.tsx`에서 인증 밖에 둠) |
| 가입 후 동의 화면 | `src/pages/ConsentPage.tsx` |
| 회원 탈퇴 창 | `src/components/DeleteAccountSheet.tsx` (프로필 수정 → 계정 → 회원 탈퇴) |
| 서버 규칙 | `firestore.rules` (**콘솔에 다시 게시해야 해요**) |

## 흐름

```
로그인 → (동의 안 했거나 버전이 바뀜) 동의 화면 → 아기 정보 입력 → 앱
```

- 동의 항목(모두 필수): 이용약관 / 개인정보 수집·이용 / **건강 관련 정보(민감정보) 별도 동의** / 만 14세 이상·보호자 확인
- 동의 기록은 계정 문서 `users/{uid}.consent = { terms, privacy, sensitive, at }`에 약관 버전과 함께 남아요.
- **동의 안 함**: 막 가입하던 중이면 계정이 바로 삭제되고, 이미 쓰던 계정이면 로그아웃만 돼요.
- **약관 고치기**: `legal.ts`의 `LEGAL_VERSIONS` 날짜를 바꾸면 모든 사용자에게 동의 화면이 다시 나와요.
- **회원 탈퇴**: 서버의 데이터 문서 → 가입 기록 → 로그인 계정 순으로 지우고, 이 기기의 사용자 데이터도 지워요. 로그인한 지 5분이 지났으면 구글 계정 확인 창이 한 번 나와요.
- 로그인 없이 계정 삭제를 요청할 수 있도록 `/delete-account` 페이지에 이메일 요청 방법을 적어 뒀어요(Play 스토어 '데이터 삭제 URL'에 이 주소를 넣어요).

## 공개 전에 할 일

1. `src/data/legal.ts`의 `OPERATOR`(이름·문의 이메일·보호책임자·데이터 리전)를 채워요. 비어 있으면 문서 위에 '운영자 정보 입력 필요' 안내가 떠요.
2. 본문은 **일반적인 구조의 초안**이에요. 법률 전문가나 개인정보보호위원회 '개인정보 처리방침 작성지침'으로 한 번 검토해 주세요. 특히 국외 이전(Google·Vercel), 보유 기간, 만 14세 미만 항목.
3. Firebase 콘솔 → Firestore → 규칙에 `firestore.rules`를 다시 게시해요. (동의 기록 저장·탈퇴 삭제 권한이 새로 들어갔어요. 게시하지 않으면 동의 저장과 탈퇴가 거부돼요.)
4. 광고(AdSense·AdFit 등)를 붙일 때: 방침 7항(광고)을 고치고 `LEGAL_VERSIONS`를 올려 다시 동의를 받아요. 아기·건강 정보는 광고에 쓰지 않아요.
5. 광고·제휴 신청 때 개인정보 처리방침 URL = `https://<도메인>/privacy`, 계정 삭제 안내 = `https://<도메인>/delete-account`.

## 추가된 수집·처리 (방침에 반영됨)
문의·오류 신고(`feedback`·`errors`), 가족 공유(구성원 이름 표시), 성장 기록(키·몸무게·머리둘레). 새 항목을 더하면 `legalText.ts`를 고치고 `LEGAL_VERSIONS`를 올려요. 광고를 켤 때는 방침 7항을 고치고 같은 방식으로 재동의를 받아요(docs/MONETIZATION.md).

## 알아 둘 점

- 서버 규칙은 동의 여부를 데이터 쓰기 조건으로 걸지 않았어요(동의 전 첫 동기화가 막혀 오류로 보이는 걸 피하려고). 동의 화면은 앱 단에서 막아요.
- 가짜(mock) 로그인에서도 같은 흐름이 동작해요(동의·탈퇴 모두 이 브라우저 저장소 기준).
- 실제 Firebase 로그인으로 탈퇴(재인증 팝업, 문서·계정 삭제)는 이 환경에서 확인하지 못했어요. Firebase 설정 후 한 번 직접 해 보세요.
