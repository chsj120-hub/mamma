# 개인정보 처리방침 자체 점검표

우리 방침(`src/data/legalText.ts`의 `PRIVACY`)을 개인정보 보호법이 요구하는 처리방침 기재사항과 비교한 점검표예요. **법률 자문이 아니에요.** 조문 번호와 요건은 제가 확인한 공개 자료(개인정보보호위원회 국외이전 안내 페이지 등)와 일반적인 이해를 바탕으로 정리했고, "확인 필요"는 아래 원문으로 직접 대조하세요.

- 대조 원문: 개인정보보호위원회 **「개인정보 처리방침 작성지침」**(2025년 4월 개정본이 있다고 알려져 있어요) — `pipc.go.kr`에서 내려받아요. 개인정보 보호법 시행령 제31조 제1항이 기재사항을 정해요.
- 점검 날짜: 2026-11-02. 방침 시행일(버전): `LEGAL_VERSIONS.privacy`.

## 1. 법정 기재사항 점검

| 3 | 처리하는 항목 | 1항 | ✅ | 항목을 늘리면 방침과 `LEGAL_VERSIONS`를 함께 고쳐요 |

## 2. 서비스 특성에 따른 추가 점검

| 항목 | 상태 | 메모 |
|---|---|---|
| **민감정보(건강정보) 별도 동의** | ✅ 구현 | 알레르기 반응·섭취 기록에 대해 일반 동의와 분리된 체크로 받고 버전·시각을 기록해요. 이 정보가 법상 민감정보(건강)에 해당하는지, 동의 문구가 충분한지는 상담 때 물어보세요 |
| **만 14세 미만 아동 정보** | 🟡 확인 필요 | 아기는 만 14세 미만의 정보주체예요. 보호자(가입자)가 직접 입력하고 "만 14세 이상, 보호자로서 입력" 체크로 확인하는 구조가 법정대리인 동의 요건(법 제22조의2)을 충족하는지 확인 필요. 아기 이름은 애칭 허용 |
| 동의 철회·탈퇴 경로 | ✅ | 프로필 수정 → 회원 탈퇴, `/delete-account` 안내 |
| 최소 수집 | ✅ | 주민번호·위치 미수집. 아기 이름·생일, 이메일, 식단·큐브·건강 기록 |
| 접근 통제 | ✅ | Firestore 보안 규칙(본인·가족 구성원만), 가족 구성원 제거·탈퇴 처리 |
| 개인정보 보호책임자 지정 | ✅ | 입력됨. 개인(비사업자) 운영자도 지정해야 하는지·본인이 맡아도 되는지 확인 필요 |
| 유출 사고 대응 | 🔲 | 유출 시 정보주체 통지와 개인정보보호위원회·KISA 신고 의무가 있어요(신고 기한은 확인 필요, 72시간이라고 알고 있어요). 대응 절차를 한 장으로 만들어 두면 좋아요 |
| 운영자 접근 | 🟡 | 관리자 키로 Firestore 전체를 읽을 수 있어요. 키 보관(프로젝트 밖, git 제외, GitHub Secrets)과, 통계 스크립트가 식단 내용을 읽지 않는다는 점을 방침에 한 줄 |
| 개인정보 열람 로그 | 🔲 | 필수는 아니지만 관리자 접근 기록을 남기면 좋아요 |
| 문의·오류에 개인정보가 섞일 수 있음 | ✅ | 안내문에 "아기 정보는 같이 보내지지 않아요"라고 적었어요. 이용자가 본문에 적는 정보는 통제 불가 |

## 3. 방침 문구에 반영하면 좋을 개정안(상담 뒤 한 번에)
상담에서 답을 받은 뒤 아래를 한꺼번에 반영하고 `LEGAL_VERSIONS`를 한 번만 올리면 테스터가 재동의 화면을 한 번만 봐요.
1. 국외 이전 항목 신설(6항을 위탁과 분리): 이전받는 자, 국가, 시기·방법, 이용 목적·보유 기간, 거부 방법, 근거 조문.
2. 파기 절차·방법 항목 신설.
3. 쿠키·방문 통계의 거부 방법.
4. 안전성 확보조치 구체화.
5. 방침 변경 이력(이전 버전 열람).
6. (광고 전) 행태정보 항목.

## 4. 상담에서 물어볼 질문 (118·법령해석지원센터용)
1. 아기의 알레르기·섭취 기록을 보호자가 입력하는 서비스에서, 별도의 민감정보 동의 방식(체크박스+버전 기록)이 충분한가요?
2. 정보주체가 만 14세 미만 아기이고 입력자가 보호자일 때, 법정대리인 동의 확인을 어떻게 해야 하나요? 지금의 체크 문구로 충분한가요?
3. Google(Firebase, 미국), Cloudflare, Vercel 같은 해외 서비스를 쓰는 것이 국외 이전에 해당하나요? 해당하면 어느 요건(처리위탁·보관 고지 등)으로 처리방침에 쓰면 되나요?
4. 가족 공유(이용자가 다른 보호자를 초대해 같은 기록을 함께 보는 기능)가 제3자 제공에 해당하나요?
5. 개인(사업자 등록 전)이 운영해도 개인정보 보호책임자 지정과 처리방침 공개 의무가 같나요?
6. 접속일 기록(가구 식별값+날짜)과 문의·오류 로그의 보유 기간 표시는 어떻게 하면 되나요?
7. 유출 사고가 났을 때 신고·통지의 기한과 방법은요?
8. 광고(비맞춤)를 붙일 때 추가로 필요한 고지는요?
