# 식사 10분 전 알림

## 지금 되는 것
설정(프로필 수정 창 → **식사 10분 전 알림**)에서 켜면, 정한 먹는 시간 **10분 전**에 알려요.

- 앱(브라우저 탭, 또는 '홈 화면에 추가'한 앱)이 **열려 있는 동안** 20초마다 오늘 식단을 확인해요.
- 알림이 허용돼 있으면 **시스템 알림**(서비스 워커 `public/sw.js`로 표시), 항상 화면 위쪽에 **알림 띠**(먹었어요 / 닫기)가 떠요.
- 같은 끼니는 하루에 한 번만 알려요. 이미 '완료'로 표시한 끼니는 알리지 않아요.
- 알림 켜기는 **기기마다** 따로 저장돼요 (휴대폰에서 켜도 PC는 그대로).

코드: `src/lib/notify.ts`(시각 계산·알림 표시), `src/components/MealReminders.tsx`(확인 반복·띠), `src/components/NotifySettings.tsx`(설정).

## 한계 (중요)
웹앱은 **닫혀 있을 때 스스로 깨어나서 알림을 띄울 수 없어요.**

| 상황 | 알림 |
|---|---|
| 앱이 열려 있음 (PC 탭, 휴대폰 화면 켜짐) | 됨 |
| 탭이 백그라운드 | 대체로 됨 (브라우저가 타이머를 1분 단위로 늦출 수 있어요) |
| 휴대폰 화면이 꺼졌거나 앱을 완전히 닫음 | **안 됨** |
| 아이폰 사파리 일반 탭 | 시스템 알림 불가. 사파리에서 **공유 → 홈 화면에 추가**한 앱에서만 가능 (iOS 16.4 이상) |

그래서 지금은 "식사 시간에 앱을 열어 두는" 분께 맞아요. 닫혀 있어도 울리게 하려면 아래 방식이 필요해요.

## 닫혀 있어도 울리게 하려면: 서버 푸시 (다음 단계)
1. **FCM(Firebase Cloud Messaging) 웹 푸시**를 붙여요. 기기마다 알림 토큰을 받아 `users/{uid}/devices/{토큰}`에 저장해요(알림을 켠 기기만).
2. **Cloud Functions 스케줄 함수**(1분마다)가 식단 문서를 읽어 "10분 뒤 먹는 끼니"를 찾고, 그 사용자의 기기 토큰으로 푸시를 보내요. 보낸 끼니는 기록해 중복을 막아요.
3. 휴대폰 OS가 푸시를 받아 앱이 닫혀 있어도 알림을 보여 줘요. 서비스 워커(`sw.js`)에 `push` 이벤트 처리를 더하면 돼요.

필요한 것: Firebase **Blaze(종량제) 요금제**(스케줄 함수 때문에, 소규모면 무료 한도 안에서 거의 0원), 함수 코드, 알림 토큰 저장 규칙. 시간대는 한국 시간으로 계산해야 하고, 사용자가 식사 시간을 바꾸면 다음 확인 때 자동으로 따라가요.

대안: 알림 시간에 맞춰 **구글 캘린더 일정**을 만들어 주는 방식도 있어요(앱 닫혀도 휴대폰 캘린더가 알림). 구글 캘린더 권한 동의가 추가로 필요해요.

## 직접 확인하기
1. 프로필 수정 → 식사 10분 전 알림 **켜기** → 알림 허용 → **테스트 알림 보내기**.
2. 오늘 식단의 끼니 시간을 지금으로부터 10분 안으로 맞추면(예: 지금이 9:55면 10:00), 20초 안에 알림 띠와 시스템 알림이 떠요.
