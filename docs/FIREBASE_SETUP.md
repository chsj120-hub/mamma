# 구글 로그인 + PC·모바일 동기화 설정 (Firebase)

코드는 모두 들어 있어요. 아래 설정만 하면 켜져요. **설정하지 않으면** 가짜(mock) 로그인으로 동작하고 데이터는 그 브라우저에만 저장돼요(개발·화면 확인용).

## 어떻게 동기화되나요?

```
 모바일 ──┐                          ┌── PC
          │   같은 구글 계정(uid)     │
          └─▶  Firestore  users/{uid}/data/{키} ◀─┘
               (내 데이터는 나만 읽고 쓰기 — 보안 규칙)
```

1. 어느 기기에서든 같은 **구글 계정**으로 로그인하면 같은 `uid`가 나와요. 데이터는 `uid`별 칸에 저장돼요.
2. **저장**: 화면에서 바꿀 때마다 먼저 기기에 저장하고, 0.8초 뒤 서버(Firestore)로 올려요.
3. **불러오기**: 로그인할 때 서버 데이터를 가져와요.
4. **실시간 반영**: 앱이 열려 있으면 다른 기기에서 바뀐 값이 서버를 거쳐 바로 화면에 나타나요 (Firestore 실시간 구독).
5. 올리는 데이터: 아기 프로필·식사 시간, 식단, 홈큐브, 알레르기 반응 기록, 마일스톤. 실행취소 기록과 화면 보기 설정(월간/주간 등), 알림 켜기는 기기마다 따로예요.
6. 가입 규칙: **모바일·PC 모두 로그인 화면에서 바로 가입돼요.** (`users/{uid}` 문서가 가입 기록이에요. 로그인 시 PC에서만 막는 규칙은 없어요.)

## 1. Firebase 프로젝트 만들기 (콘솔에서 직접)
1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: `mamma`). 애널리틱스는 꺼도 돼요.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → Google → 사용 설정**, 프로젝트 지원 이메일 선택 후 저장.
3. **Authentication → 설정 → 승인된 도메인**에 배포 주소 추가: `mamma-one.vercel.app` (`localhost`는 기본 포함). 미리보기 배포 주소도 쓰면 그것도 추가해요.
4. **빌드 → Firestore Database → 데이터베이스 만들기 → 프로덕션 모드** (지역 `asia-northeast3` 서울 권장).
5. **Firestore → 규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여 넣고 **게시**. 게시하지 않으면 로그인해도 저장이 거부돼요.
6. **프로젝트 설정 → 일반 → 내 앱 → 웹 앱(</>) 추가** → 나오는 `apiKey`, `authDomain`, `projectId`, `appId` 4개를 메모.

## 2. 값 넣기
- 내 PC에서 테스트: `.env.example`을 `.env.local`로 복사해 4개 값을 채우고 `npm run dev`.
- 인터넷(Vercel): 프로젝트 → **Settings → Environment Variables**에 같은 이름 4개(`VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID`)를 추가하고 **Redeploy**.

> 웹 앱 설정값은 비밀키가 아니에요. 접근은 보안 규칙과 승인된 도메인이 막아 줘요. `.env.local`은 git에 올리지 않아요.

## 2-1. (선택) App Check
`VITE_FIREBASE_APPCHECK_KEY`(reCAPTCHA v3 사이트 키)를 넣으면 켜져요. 설정 순서는 `docs/OPERATIONS.md` §3.

## 3. 확인하는 방법
1. 모바일(또는 휴대폰 폭 창)에서 **Google로 시작하기** → 구글 계정 선택 → 약관 동의 → 아기 정보 입력 → 홈.
2. 식단 하나를 추가해요.
3. PC에서 같은 사이트 → **Google로 로그인**(같은 계정) → 방금 만든 식단이 보이면 성공.
4. PC에서 식단을 고치면 모바일 화면에도 바로 바뀌는지 봐요 (두 기기 모두 앱을 연 상태).
5. PC에서 처음 보는 구글 계정으로 로그인하면 바로 가입(약관 동의 → 아기 정보 입력)돼야 해요.

## 4. 알아 둘 점
- **동시에 같은 부분을 고치면 마지막 저장이 이겨요.** 식단은 통째로 한 문서라서, 두 기기가 오프라인에서 각각 고치고 나중에 연결되면 한쪽 변경이 덮일 수 있어요. 둘 다 온라인이면 실시간 반영 덕에 거의 생기지 않아요.
- 카카오톡·인스타그램 같은 **앱 안 브라우저에서는 구글 로그인이 막혀요**(구글 정책). 크롬·사파리 같은 일반 브라우저로 열어야 해요.
- 휴대폰에서 팝업이 막히면 "팝업이 막혀 있어요" 안내가 나와요. 사이트의 팝업을 허용해 주세요.
- 저장되는 개인정보는 **아기 이름·생년월일, 식단·큐브 기록**과 로그인한 구글 계정이에요 (그 외 민감 정보는 받지 않아요).
- 이용약관·개인정보 처리방침 페이지, 가입 때 동의 화면, 회원 탈퇴(데이터 삭제)는 들어 있어요. 공개 전에 할 일은 `docs/LEGAL.md`를 보세요. **규칙(`firestore.rules`)이 바뀌었으니 5단계처럼 다시 게시해야 동의 저장·탈퇴가 돼요.**
- 카카오·네이버 로그인은 다음 단계예요 (서버 함수가 필요해요).
