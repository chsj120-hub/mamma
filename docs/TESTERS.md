# 테스터 안내 (Threads 등에 올릴 글과 운영 메모)

## 테스터에게 보낼 안내문 (복사해서 쓰세요)

> **맘마 이유식 식단 플래너 테스터 모집**
> 아기 월령에 맞춰 이유식 식단을 짜고, 홈큐브 재고·성장 기록을 관리하는 웹앱이에요. 설치 없이 링크로 열어요.
>
> 1. 링크 접속: (주소)
> 2. Google로 시작하기 → 약관 동의 → 아기 이름(애칭 가능)·생일 입력
> 3. 식단을 짜 보고, 먹은 끼니는 '완료'를 눌러 보세요. PC에서도 같은 계정으로 열면 이어져요.
> 4. 불편한 점·오류는 앱의 **프로필 수정 → 내 기록 → 문의·오류 신고**로 보내 주세요 (아기 정보는 같이 안 보내져요).
> 5. 휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 쓰면 앱처럼 바로 열려요.
>
> 아기 이름은 애칭으로 적어도 괜찮아요. 식단·알레르기 안내는 참고용이고, 아기 건강이 걱정되면 소아청소년과와 상담해 주세요.

## 백업 기능은 어디에 있나
**프로필 수정 → 내 기록** 에 있어요.
- 모바일: 홈 화면의 아기 카드 → **프로필 수정** → 아래로 내리면 "내 기록".
- PC: 왼쪽 메뉴 아래 프로필 카드 → **프로필 수정** → "내 기록".
- **기록 내려받기**: 식단·홈큐브·성장 기록·알레르기 반응·마일스톤·아기 프로필을 `mamma-backup-날짜.json` 파일 하나로 저장해요. 아래에 "마지막으로 내려받은 날"이 표시돼요.
- **백업 파일 가져오기**: 파일을 고르면 어떤 항목이 바뀌는지 보여 주고, "지금 기록 바꾸기"를 눌러야 적용돼요.

백업은 필수는 아니에요. 로그인한 계정의 기록은 서버에 저장되고 다른 기기에서도 보여요. 백업은 **보험**(실수로 지웠을 때, 계정을 바꿔 옮길 때)이에요.

## 테스터에게 백업을 안내해야 하는 때
| 상황 | 안내할 것 |
|---|---|
| 도메인을 바꾸기 전(예: `*.vercel.app` → 자체 도메인) | 새 주소에서는 로그인을 다시 해야 해요. 서버에 저장된 기록은 돌아오니 **"기존 주소에서 로그인된 상태인지만 확인"**하게 하고, 마음이 안 놓이면 미리 기록을 내려받게 해요 |
| 큰 업데이트 전 | 기록 내려받기 한 번 |
| 다른 구글 계정으로 옮기고 싶을 때 | 내려받기 → 새 계정으로 로그인 → 가져오기 |
| 가족 기록에 참여할 때 | 내 기록이 가족 기록으로 바뀌므로 먼저 내려받기 (화면에서도 안내해요) |

## 운영 메모
- 문의·오류는 Firebase 콘솔 → Firestore → `feedback`, `errors`에서 확인해요 (`docs/OPERATIONS.md`).
- 활성 가구와 재방문은 `npm run stats` (`docs/ANALYTICS.md`).
- 약관·방침을 바꾸면 테스터가 다음 접속 때 동의 화면을 다시 봐요(정상이에요). 미리 알려 두면 덜 놀라요.
