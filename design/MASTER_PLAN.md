# 🥣 맘마 이유식 식단 플래너 & 육아 교육 게임 플랫폼 (ClassPlay v6.0) - 종합 기획 및 시스템 설계서

본 문서는 **맘마 이유식 식단 플래너 (ClassPlay v6.0 Production)**의 전체 기획 의도, 아키텍처 설계도, 기능 명세 및 UI/UX 디자인 시스템을 총망라하여 정리한 마스터 기획서입니다.

---

## 📋 1. 기획 의도 및 서비스 개요 (Product Vision)

### 1.1 기획 배경
- **초보 부모의 이유식 고민 해결**: 초기(4~6개월) 미음부터 중기(7~9개월) 묽은 죽, 후기/완료기(10~12개월) 진밥 및 유아식 이행까지 월령별로 복잡하고 까다로운 이유식 스케줄과 철분/알레르기 관리를 누구나 쉽고 직관적으로 계획할 수 있도록 지원합니다.
- **제로 API 키 & 실시간 동기화**: 외부 유료 LLM 의존성 없이 순수 로직 및 AI 추천 알고리즘, 실시간 데이터 동기화(SSE / Firebase)를 결합하여 비용 부담 없고 환각 현상 없는 안정적인 이유식 관리 환경을 제공합니다.

### 1.2 핵심 가치 (Core Value Proposition)
1. **정밀 월령 맞춤형 D-Day 계산**: 아기 생년월일을 기준으로 UTC 및 밀리초 보정 연산을 통해 매일 정확한 생후 일수(D+Day)와 발달 단계를 자동 안내합니다.
2. **지능형 AI 추천 & 균형 분석**: 철분(소고기) 필수 공급 원칙과 10대 알레르겐(계란노른자, 땅콩 등) 3일 테스트 주기를 준수하는 자동 식단 조합 및 주간 영양 균형 리포트를 제공합니다.
3. **안심 재고 및 유통기한 관리**: 홈큐브(HomeCube) 냉동 보관함의 재고 부족(2개 미만) 및 유통기한 임박(3일 이내) 알림을 통해 식재료 낭비를 방지합니다.
4. **완벽한 데이터 무결성 (실행 취소/스냅샷)**: 식단 수정, 일괄 채우기, 알레르기 대체 시 자동으로 스냅샷을 기록하여 언제든지 이전 버전으로 안전하게 되돌릴 수 있습니다.

## 🏗️ 2. 시스템 아키텍처 및 기능 전체 설계도 (System Architecture)

```
[ 클라이언트 (React SPA / Vite / Tailwind CSS / Framer Motion) ]
       │
       ├─ UI 뷰 & 컴포넌트 레이어 (CalendarView, WeeklyTableView, GrowthReportCard 등)
       ├─ 상태 관리 & 로컬 스토리지 영구 저장 (MealPlanDay, BabyProfile, HomeCube, Snapshots)
       └─ 지능형 추천 및 영양 분석 엔진 (Recommender.ts, NutritionAnalyzer.ts)
       │
[ 백엔드 / 실시간 연동 레이어 (Node.js / Express / SSE / Firebase RTDB & Auth) ]
       │
       ├─ RESTful API & 실시간 서버 전송 이벤트 (SSE)
       ├─ 소셜 로그인 (Google, Kakao, Naver OAuth 2.0 & Firebase Auth)
       └─ 개발자 실시간 알림 시스템 (Telegram Bot API / Cloud Functions 연동)
```

## ⚙️ 3. 핵심 기능 명세 (Core Feature Specifications)

### 3.1 월령별 D-Day 및 아기 프로필 관리
- **정밀 일수 계산**: 아기 생년월일과 현재 날짜 간의 밀리초 보정 및 UTC 기준 연산(`Date.UTC`)을 적용하여 타임존 오차 없이 정확한 생후 일수(예: `D+224일차`)를 실시간 도출합니다.
- **프로필 모달**: 아기 이름, 생년월일, 이유식 단계, 1회 목표 섭취량, 일일 식사 횟수를 직관적으로 수정할 수 있습니다.

### 3.2 캘린더 & 주간 식단 플래너
- **월간/주간 뷰 전환**: 캘린더 형태와 주간 표 형태를 자유롭게 전환하며 일자별 메인 베이스, 고기, 채소 1·2, 과일, 간식, 알레르기 테스트 여부를 관리합니다.
- **완료 상태 토글**: 오늘의 식단 요약 카드 및 캘린더 셀에서 클릭 한 번으로 '예정' ⇄ '완료' 상태 전환과 함께 기분 좋은 체크 애니메이션 및 녹색 하이라이트 효과를 제공합니다.

### 3.3 홈큐브 보관함 & 스마트 알림 시스템
- **재고 부족(Low Stock) 경고**: 큐브 수량이 `2개 미만`으로 떨어지면 보관함 및 드로어에서 ⚠️ 경고 아이콘과 애니메이션 배지가 표시됩니다.
- **유통기한 임박 알림 (Expiry Notification)**: 제조일과 권장 유통기한(고기 21일, 채소 14일 등)을 계산하여 **3일 이내에 소진해야 하거나 기한이 만료된 큐브**를 상단 알림 배너로 긴급 안내합니다.

### 3.4 자동 스냅샷 및 버전 복구 (Undo / History)
- **주요 편집 자동 백업**: 식단 수정, 삭제, AI 자동 추천 적용, 알레르기 재료 일괄 대체 작업 시 현재 캘린더 상태가 자동으로 스냅샷(`pushSnapshot`)에 기록됩니다.
- **실행 취소 모달**: 하단 툴바의 `[↩️ 실행취소]` 버튼을 통해 최근 저장된 버전별 타임라인을 확인하고 원클릭으로 안전하게 이전 상태로 복구할 수 있습니다.

### 3.5 이유식 마일스톤 체크리스트 & 성장 리포트
- **월령별 맞춤 가이드**: 4~6개월(초기 미음), 7~9개월(중기 죽), 10~12개월(후기/완료기 진밥)에 따른 적정 식감과 1회 권장량을 제시합니다.
- **인터랙티브 체크리스트**: 발달 단계별 체크박스를 통해 아기의 이유식 적응 과정을 직접 체크하고 관리할 수 있습니다.

## 🎨 4. 디자인 시스템 및 UI/UX 테마 구조 (Design System)

### 4.1 UI/UX 디자인 원칙
- **부모 중심의 따뜻하고 직관적인 인터페이스**: 복잡한 정보는 카드형 레이아웃으로 분리하고, 중요한 알림과 경고는 애니메이션 펄스/바운스 효과로 주목도를 높였습니다.
- **반응형 디자인 (Mobile-First)**: 스마트폰 주방 환경과 PC 데스크톱 환경 모두에서 최적화된 터치 타겟과 레이아웃을 제공합니다.

### 4.2 테마 색상 팔레트 (Theme Selector)
사용자 설정에서 실시간으로 전환하고 `localStorage`에 영구 저장되는 3가지 컬러 팔레트:
1. **Warm Amber (따뜻한 웜앰버 - 기본값)**:
   - 포인트 컬러: 앰버/오렌지 (`#f59e0b`, `bg-amber-500`)
   - 감성: 따뜻하고 친근하며 가정적인 이유식 분위기.
2. **Soft Blue (부드러운 소프트블루)**:
   - 포인트 컬러: 소프트 블루/스카이 (`#3b82f6`, `bg-blue-500`)
   - 감성: 산뜻하고 깨끗하며 신뢰감을 주는 헬스케어 스타일.
3. **Nature Green (네이처 그린)**:
   - 포인트 컬러: 에메랄드 그린 (`#10b981`, `bg-emerald-500`)
   - 감성: 유기농 식재료와 자연의 싱그러움을 담은 친환경 스타일.

## 🚀 5. 상용화 및 운영 가이드 (Production Deployment)

1. **빌드 및 실행**:
   - `npm install` 후 `npm run dev`로 로컬 개발 서버 구동.
   - `npm run build`로 프로덕션 빌드 검증 (`tsc --noEmit` 린트 통과).
2. **보안 및 배포**:
   - Vercel, Netlify 또는 Firebase Hosting에 연동하여 HTTPS 환경에서 안전하게 운영.
   - 소셜 로그인 토큰 및 알림 웹훅(Telegram Bot API 등) 연동을 통한 개발자 실시간 피드백 수신 체계 구축.
